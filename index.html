extensions ¶

Optional packages for the canVODpy ecosystem

Each of these packages does one job alongside canVODpy. Install only the one you need: a naming recipe for the files your receiver writes, an Airflow DAG for a site's daily runs, or an adapter to exchange data with another GNSS-T program.

Start here Contribute

Packages¶

  •   canvod-filemap

    Maps the files your receiver writes to their canVOD file names, so a run finds your data without you renaming anything on disk.

    Naming recipes

  •   canvod-airflow

    One daily DAG per site, plus one to backfill a date range. The tasks run the code of canvodpy run.

    Airflow DAGs

  •   canvod-adapters

    Reads and writes observations and VOD for another GNSS-T program, for example gnssvod, and checks each import against canvodpy's contracts.

    Data exchange

canVODpy is a lean core that works fully without any of these packages. Each one is optional, installs on its own, and follows its own release cadence. For the packages canVODpy ships and how to set a site up, see canVODpy.
